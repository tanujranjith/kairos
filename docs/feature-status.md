90 tests pass for road sampling/directed routing, authored crossing coverage, traffic signals/priorities/queues/lane changes/recycled scheduling, combined-slip tire limits, ordered race timing, false starts, pit exclusion, shortcut progress, lapped classifications, save sanitization, controller edges/repetition, course/junction/road terrain clipping, audio/tunnel mixing, streaming transactions, cell buffers, material maps, six-car mesh generation, rendering-detail policies, outward coachwork normals, roof/camera scale, deterministic grass dressing, architecture/occupied-window/pavilion buffers, solar/sky variation, the bounded continuous-normal mountain/coarse-ground mesh, and explicit road/contact layers. All six cars pass controlled acceleration/ground-contact checks. Repeated 60/30/20Hz displayed-input cadences produce matching fixed-step acceleration results.

GT and Formula eight-car weekends have completed practice, qualifying, physical player pit service and three-lap race results. In the latest weekend run seven GT entrants finished and one AI entrant timed out; all eight Formula entrants finished. Both player races finished without penalties. Earlier standalone quick-race runs finished all eight cars. This is evidence of working flows, not exhaustive AI reliability.

The supplied web-game input client and supplemental browser checks exercise six-car selection, customization, map routing, driving/reverse/reset, pause, five cameras, wet-night lighting, handling-course entry/reset/minimap and save/reload. Twenty-one synthetic controller browser checks cover actual forms, palettes, focus restoration, disconnect/reconnect, driving, pause and results. Corrupt-profile recovery, export/import, unavailable IndexedDB and failed writes pass separate fault checks. Installed Edge passes startup/driving with both WebGPU and forced WebGL2, with external hosts blocked. See [measured evidence](benchmarks.md) and the retained `output/` reports.

Northstar now has physical skidpad, slalom, braking, bump, banking, gradient, curb, jump and barrier surfaces. The quantitative suite covers six-car acceleration and Velara handling in dry/wet/worn conditions. Engine, whine, road, wind, rain, tire-slip and impact synthesis, shifts, cockpit filtering and tunnel reflections are implemented. Offline PCM tests exercise output/silence and browser checks verify blocked-autoplay recovery without blocking entry to a drive.

The environmental graphics continuation adds five original building families, roof/storefront details, distinct glazing and dusk-lit windows, flush city pavement, nonperiodic meadow tint, smoother outer ridges and a directional generated sky. Seven actual region/light/weather captures and a separate five-style inspection view pass with four wheel contacts and no page/external-request errors. This is an improvement to the stylized world, not delivery of the mockups' realism or the complete approved game.

Traffic now uses explicit right-hand lanes and legal turn connectors shared with navigation. Signals include amber/all-red clearance, visible synchronized lamps, turn reservations, through-road priority, left-turn yielding and blocked-exit checks. Staggered 10Hz decisions drive nearby Havok vehicles and lightweight distant actors. Physical tests cover red/green departure, turns, turning around, stopping, passing, a merge, obstruction release and tier transitions; see [traffic details](traffic.md). These are selected-scenario checks, not exhaustive traffic acceptance.

## Simplified or incomplete relative to the approved plan

- The [graphics upgrades](graphics.md) add shaped enclosed-car bodies, separate glazing/interiors, rebuilt GLBs and camera mounts, branched/leaf-card vegetation, grass, normal-mapped surfaces/water, facade details, shadows, a rebuilt gallery with planar floor reflection and a locally bundled CC0 photographic view. This is still stylized procedural art, not the mockups' photorealistic quality; car families share topology and all regions need more dressing/polish.
- Bulk world generation now runs asynchronously in a same-origin worker with cancellation, resource leases, collision-first loading gates and circuit/pit reservation. [Streaming checks](streaming.md) pass delay/failure/retry/cancellation and short repeated-region resource cycles. [Explicit road layers](road-layers.md) now include an eight-metre overpass, separate terrain/deck height, actual per-wheel surface identity, and height-aware reset/navigation/arrivals. Special fixtures and installation remain on the main thread; private circuit-access routing and real-time maximum-speed/endurance budgets remain incomplete.
- Traffic's authored graph and physical/distant tiers are implemented, but broad multi-car congestion/fairness endurance, all-junction tuning, wet/night hazards and dense-traffic CPU budgets remain unverified. Ambient density can temporarily fall during transitions. Junction geometry/signage is functional but simplified.
- AI passing and defending are basic. Player pit service is physically verified, but automatic AI pit strategy, safe rejoining, dense 16-car fields and flags still need adversarial interaction tests. Rules are a compact implementation, not a complete motorsport rulebook. Pit progress is projected onto the circuit, not a separately validated ordered pit-checkpoint chain.
- Handling-course checks are development-host results, primarily Velara maneuvers plus six-car acceleration. Repeated tests do not yet cover every class/setup/surface combination or certify maximum speeds. Catalog performance labels remain tuning targets and differ from measured acceleration.
- Player paint/glass now use a bounded, double-buffered local scene probe, with analytic fallback/background lighting and one face drawn per displayed frame. Capture coverage and roughness filtering are approximations; target-hardware profiling is still required. Four presets have distinct resolution/shadow/density/detail settings, FXAA and optional bloom; automatic benchmarking, adaptive resolution and the full higher-end effect set are not implemented.
- Audio remains synthesized rather than recorded multi-layer automotive audio; subjective realism and hardware output/latency still need listening tests. Night headlights are working, with limited visual realism.
- Six compressed GLB pairs are loaded at runtime, with procedural fallback. Traffic/racing now switch detail with hysteresis and preserve four-wheel animation/customization. Both levels remain resident; finer-grained asset streaming and a KTX2 pipeline remain incomplete.
- Controller form navigation and disconnect/reconnect are now covered by synthetic standard-gamepad tests. No physical controller or vibration hardware was available. Native OS save dialogs are outside DOM controller navigation.
- Production now consolidates Babylon into a separately cacheable hashed engine bundle, reducing the sampled initial resource count from 217 to 18. Six repeated cold 25Mbps/40ms software-rendered runs reached the menu in 5.475–17.134s (median 5.680s), transferring about 11.0MB through driving/handling entry. Earlier 28.9s / 25.9s failures and a profiling timeout remain recorded; the intermittent cause is not proven. Menu readiness does not include first-drive streaming, so the full initial-playable 20-second target is not certified. No target-laptop FPS, GPU/process memory, 30-minute real-time endurance or device-loss recovery claim is made.
- Installed Chrome and Edge now both pass startup/driving through WebGPU and forced WebGL2, with third-party runtime hosts blocked. Earlier Chrome launch failures remain in the historical notes; the latest four-path browser check succeeds. No HTTPS destination has been authorized or deployment verified.

Do not represent this document or the existence of a menu option as proof that every acceptance criterion has passed.
